# わりかん

友達との飲み会や旅行で「誰が何を払ったか」をスマートフォンから記録し、必要な送金額を自動計算するシンプルな割り勘アプリです。スマートフォンでの利用を主に想定しています。

## アプリを開く

スマートフォンのブラウザから、次のリンクを開いてください。

**[わりかんを開く](https://hiwa-ghoti.github.io/split-the-check/)**

繰り返し使う場合は、ブラウザの共有メニューからブックマークへの追加、または「ホーム画面に追加」を行うとすぐに開けます。

## 主な機能

- イベント名を作成日から自動生成
- 同じ日にイベントがある場合は、重複して作成せず既存イベントを開く
- メンバー、支払者、金額、割り勘対象者を記録
- 同じ二人の間にある相互の送金を相殺し、差額1件に集約
- 送金ごとに精算済み・未精算を管理
- 未精算の送金を上、精算済みの送金を下に表示
- 各人の収支詳細を折りたたみ表示
- イベント名の変更、支払い・メンバー・イベントの削除
- ブラウザ内にデータを保存

## セットアップ

```bash
cp .env.example .env.local
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開きます。

`.env.local` は省略できます。未設定の場合、アプリ名には既定値が使われます。

## 使い方

1. スマートフォンで[アプリ](https://hiwa-ghoti.github.io/split-the-check/)を開く
2. 「作成する」をタップして当日のイベントを開く
3. 割り勘に参加するメンバーを追加する
4. 支払いごとに内容、金額、支払った人、割り勘する人を入力する
5. 「精算結果」の送金メモで、誰が誰へいくら送るか確認する
6. 送金が終わった項目を「精算済みにする」へ切り替える

同じ日にもう一度「作成する」をタップした場合は、新しいイベントを増やさず、その日の既存イベントを開きます。各人の支払額と負担額は「各人の収支」をタップすると確認できます。

イベント、支払い、精算状態は、使用したスマートフォンのブラウザ内に保存されます。別の端末やブラウザとは共有されません。ブラウザのサイトデータを削除すると記録も削除されます。

## スクリプト

| コマンド | 説明 |
|----------|------|
| `npm run dev` | 開発サーバー |
| `npm run build` | 静的サイトを `out/` に生成 |
| `npm run lint` | ESLint |
| `npm test` | 精算ロジックのテスト |

静的ビルドをローカルで確認する場合:

```bash
npm run build
python -m http.server 3000 --directory out
```

## GitHub Pages

`main` ブランチへプッシュすると、GitHub Actionsが依存関係のインストール、テスト、Lint、静的ビルドを順に実行し、成功した成果物をGitHub Pagesへデプロイします。

- イベント詳細は静的ホスティングに対応するため `/sessions?id=...` 形式です。
- リポジトリ名に合わせて `/split-the-check` のベースパスをビルド時に設定します。
- サーバーやデータベースは使用しません。

## ディレクトリ構成

```text
src/
  app/                 # ルーティング・ページ・API
  components/
    ui/                # 汎用 UI
    layout/            # ヘッダー等
    warikan/           # 割り勘 UI
  lib/warikan/         # 精算ロジック・保存
  types/               # 共有型
  hooks/               # クライアントフック
```
